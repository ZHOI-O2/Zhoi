# 나폴리탄 14종 — 라벨 데이터

제조사 규격서 `15종 나폴리탄 규격서.xlsx`(실제 14종)에서 추출한 한글 표시사항 데이터.

## 파일

| 파일 | 내용 |
|---|---|
| `extract.py` | 규격서 xlsx 추출기. 시트마다 표 시작 행이 달라 **행을 라벨로 탐색**한다 (고정 행 번호 금지) |
| `kor.py` | 영문 원재료 → 한글 표기, 복합원료 합산 + 배합비 내림차순 재정렬, 알레르기 추출 |
| `라벨입력데이터_14종.csv` / `.json` | 라벨 입력용 최종 데이터 |
| `나폴리탄_14종_영양성분.csv` | 9개 영양항목 + 유통기한·보관온도 |
| `나폴리탄_14종_원재료.csv` | 커버추어 그룹별 원재료·배합비 (127행) |
| `../browser/_napolitan_data.js` | 위 데이터를 브라우저에서 쓰는 형태로 생성한 것 |

재생성: `python3 extract.py <규격서.xlsx>`

## 규격서에서 발견한 결함 — 제조사 확인 필요

1. **밀크 솔티드 카라멜(#3-10)에 카라멜이 없다.** A1 배합은 `Caramel 5%` 인데 원재료 3번 항목이
   `Sugar 5%` 로 기재돼 있다. 그 결과 설탕이 26.88%(15+6.88+5)가 된다.
   제품명에 "카라멜"이 들어가는데 원재료명에 카라멜이 없으면 표시 위반 소지가 있다.
   열량도 표기 597kcal 대 계산값 622kcal 로 25kcal 어긋나며, 같은 원인으로 보인다.
   (나머지 13종은 Atwater 계수 계산과 정확히 일치)

2. **영양성분이 완전히 같은 3쌍**: 화이트 블루베리 = 화이트 스트로베리 / 다크 씨솔트 = 다크 페퍼 솔트 /
   **밀크 피넛 = 밀크 아몬드**. 특히 마지막 쌍은 땅콩 15% 대 아몬드 15% 라 지방·단백질이 달라야 정상이다.
   베이스 초콜릿 값을 복사하고 부재료를 반영하지 않은 것으로 보인다.

3. **원본 표기 불일치**: `Whole Milk Power`(오타), `PGPR(Glycerin Esters of Fatty Acids`(괄호 미닫힘),
   `Corn flakes`/`Corn Flakes`, `Sea Salt`/`Sea salt`, `Dark couverture`/`Dark Couverture`.
   한글 변환 시 통일했다.

4. **다크 72%(샘플 #1-3) 누락** — 파일명은 15종이나 실제 14종. 추가 확보 필요.

5. 규격서의 `Product name:` 칸이 14종 전부 비어 있다.
